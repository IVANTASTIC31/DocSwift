# DocSwift v0.3.1

本版本是内部自动更新兼容性修复版本。

## 修复内容

- 修复更新清单包含 UTF-8 BOM 时客户端无法解析的问题。
- 客户端现在同时兼容带 BOM 和不带 BOM 的 UTF-8 更新清单。
- 修复 Windows PowerShell 5.1 生成 `latest.json` 时自动写入 BOM 的问题。
- 后续内部更新清单将明确使用无 BOM 的 UTF-8 编码。
- 增加更新清单解析与 PowerShell 生成流程的回归测试。

## 安全性

- 保持 HTTPS 证书验证逻辑不变。
- 保持下载地址信任校验、文件大小校验和 SHA-256 完整性校验不变。
- 保持公司服务器优先、GitHub 备用源的更新策略不变。

使用 v0.2.2 或 v0.3.0 的用户可以直接更新到本版本。
