# DocSwift v0.3.2

本版本优化多卡校对确认流程与导出表头显示。

## 新功能与优化

- 校对表会完整展开长工序内容，内容超出窗口时提供竖向滚动，无需双击即可查看全文。
- 点击“确认当前工艺卡”后，自动选中下一张待确认工艺卡并同步刷新右侧详情与预览。
- 全部工艺卡确认完成后，直接打开批量导出确认窗口。
- Excel 工序号列继续写入工艺卡原始工序号，但首行表头保持空白。
- 工艺路线 Excel 导出改为保留官方模板底层结构并使用共享字符串，解决生成文件无法导入小黑湖的问题。

## 保持不变

- 继续完全离线解析 `.docx` 工艺卡，不上传任何源文件。
- 继续过滤“待焊”和用户自定义排除项。
- 批量导出仍为原子操作，重复导出同一工艺路线会替换旧数据而非重复追加。
- 自动更新继续校验发布包名称、文件大小和 SHA-256，并阻止 ZIP 路径穿越。
- 用户任务数据独立保存在 `%LOCALAPPDATA%\DocSwift`，程序升级不会清除。
