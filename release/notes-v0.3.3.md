# DocSwift v0.3.3

本版本修复工艺路线 Excel 无法导入小黑湖的问题，并提升版本号，使现有 v0.3.2 客户端能够识别更新。

## 修复

- 导出文件以官方模板 OOXML 包为基础，只更新工作表数据和共享字符串。
- 文本单元格使用模板兼容的共享字符串格式，不再使用 `inlineStr`。
- 模板样式、关系、属性、批注和 VML 等非数据部件保持原样。
- “是否锁定为最后一道工序”和“工时/分钟”保持真正空值。
- 清理数据区之外的空物理行，避免导入端误判有效范围。

## 保持不变

- 工艺路线编号、名称、工序号、工序内容和报工数配比规则不变。
- 工序号保留工艺卡原值，首行工序号表头继续保持空白。
- 原子批量导出和重复路线替换逻辑不变。
- 用户任务数据继续保存在 `%LOCALAPPDATA%\DocSwift`，更新程序不会清除任务记录。
