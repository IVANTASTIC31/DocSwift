# 工艺卡转工艺路线模板

这是一个本地桌面小程序，用来读取 Word 工艺卡，并按 Excel 流程模板格式生成工单系统导入表。

详细的需求背景、问题原因和历次功能演进见 [DEVELOPMENT_HISTORY.md](DEVELOPMENT_HISTORY.md)。

## 环境安装

需要 Windows 和 Python 3.10 或更高版本。首次使用建议在项目目录执行：

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

随后双击 `run.bat`。启动脚本会依次查找 `.venv`、`py -3` 和 PATH 中的 `python`。如果缺少 Python 或依赖，窗口会保留并显示处理方法。

## 使用方式

1. 完成首次环境安装后，双击 `run.bat`。
2. 选择一个或多个 `.docx` 工艺卡。
3. 选择 Excel 模板。
4. 选择输出文件位置。
5. 点击“解析预览”检查识别结果，再点击“生成 Excel”。

默认从 Excel 第 2 行开始写入。程序会保留模板/输出文件中的行样式，并将所有内容水平、垂直居中。

## 追加写入

“追加到已有输出文件”默认不勾选：

- 默认按模板重新生成文件，从第 2 行开始写入，并清理原有明细。
- 如果手动勾选追加且输出文件不存在：按模板创建新文件，从第 2 行开始写入。
- 如果输出文件已经存在：打开这个输出文件，从最后一条数据的下一行继续写，并覆盖保存同一个文件。

关闭程序后，本次选择的工艺卡、模板、输出路径和预览数据不会保留。

## 写入规则

- “工艺路线编号”列：`零件图号 + 零件名称`
- “工艺路线名称”列：`零件图号 + 零件名称`
- “工序/工艺路线列表”列：Word 工艺卡中的“工种”
- “工序内容”列：Word 工艺卡中的“工序内容”
- “工序号”列：使用 Word 工艺卡中的实际数字工序号，不按生成后的行数重新编号
- “类型”列：固定为 `工序`
- “报工数配比”列：固定为 `1`
- “是否锁定为最后一道工序”和“工时/分钟”列留空

程序会优先按第 1 行表头匹配列名，模板列顺序调整后仍可识别。
当前标准 9 列模板即使 D1 为空，也会按 `D=工序号、E=工序内容` 自动补全。

## 连续工序合并

如果一个有名称的工种后面存在一条或多条未重复填写工种的连续明细，程序会将它们输出为一行：

- “工序/工艺路线列表”和工序号保留该组第一条的值。
- 例如某个“车”工种包含工序 4～19，合并后工序号填写 `4`，下一工序继续使用工艺卡中的 `20`。
- 每条工序内容在同一个单元格内单独换行。
- 行高会按合并后的步骤数量自动增加。
- 空白工种续行会并入上一条有名称的工种；如果文件开头出现无归属的空白工种明细，则保持独立。
- 每条输出数据的所有单元格都会添加黑色细框线，包括内容为空的列。

## 强制排除规则

- 工种或工序内容中只要包含“待焊”，该工序就不会出现在预览和输出文件中。
- 删除“待焊”后，其他工序继续使用工艺卡中的原始工序号，不重新编号。

## 命令行用法

默认清理旧明细并重新生成：

```bat
python app.py --card "C:\path\card.docx" --template "C:\path\template.xlsx" --output "C:\path\output.xlsx" --start-row 2
```

需要追加时：

```bat
python app.py --card "C:\path\card.docx" --template "C:\path\template.xlsx" --output "C:\path\output.xlsx" --start-row 2 --append
```

## 检查
