# DocSwift v0.3.0

本版本重点优化批量工艺卡处理时的启动体验、稳定性和可诊断性。

## 新功能与优化

- 增加启动等待画面和提前单实例保护，防止启动期间重复点击。
- 增加 UTF-8 滚动日志及“查看日志”入口。
- 工艺卡识别改为后台单通道队列，识别期间界面仍可操作。
- 左侧按未识别、待识别、识别中、待确认、已确认和已导出显示真实状态。
- 支持安全移除误添加的工艺卡；不删除原始 Word，不反向修改已导出 Excel。
- 删除顶部重复的添加入口，并将“移除”改为红色危险操作按钮。
- 增加 DocSwift 项目图标，用于窗口、任务栏和 Windows 可执行文件。
- 增加异常中断状态恢复和相关回归测试。

## 保持不变

- 继续完全离线解析 `.docx` 工艺卡。
- 继续过滤“待焊”和用户自定义排除项。
- 继续保留工艺卡原始工序号并输出带边框、居中的 Excel 工艺路线。
- 用户任务数据独立保存在 `%LOCALAPPDATA%\DocSwift`，程序升级不会清除。
